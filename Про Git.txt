Про Git

Git – распределённая система управления версиями. Она хранит историю изменений файлов проекта,
позволяет вернуться к любой прежней версии и работать над проектом нескольким людям одновременно.

Основные понятия:
- репозиторий – хранилище проекта с историей изменений;
- commit – сохранённый снимок проекта с сообщением;
- branch (ветка) – отдельная линия разработки;
- merge – объединение веток;
- push / pull – отправка изменений на сервер и получение изменений с сервера.
